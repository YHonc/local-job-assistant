# 人工验收

优先使用 [合成数据预览](development.md)。真实模型、邮箱和 Push 检查应使用本人明确授权的测试账户，可能产生调用费用或外部通知。

## 岗位工作台

- 列表及卡片模式显示岗位、公司、类别和添加时间；未知时间显示“未记录”。
- 宽屏、中等宽度和手机宽度下，操作文字可读且无横向溢出；细分方向筛选区已移除。
- 搜索、类别、地点、招聘类型、状态、排序和分页可以组合使用与清空。
- 状态选择、保存反馈、撤销、详情与编辑均可用；批量操作仅影响明确选择的记录。
- 测试无申请记录的岗位编辑，以及旧状态记录，确认没有意外创建申请或改写历史。

## 外部集成

- 扩展：当前页提取、草稿、查重、人工确认；页面刷新和扩展重载后结果符合预期。
- 模型：有效/无效凭据、结构化返回、备用模型、用量统计；代理故障时不给出成功提示。
- 邮箱：IMAP 授权、时间窗口、增量同步、预筛、清洗、关联和人工确认进度建议。
- 通知：只向测试目标发送；确认发送历史、重试和避免重复提醒。
- 设置：独立保存、未保存草稿提示、导航与深链接、深浅色和键盘操作。

截图、日志和导出可能带有个人资料，保存到 Git 忽略的 `output/` 或 `local/`，不要作为默认公开附件。自动测试或合成预览通过不代表以上真实集成均已验收。
